# 桌面任务日历（TaskCalendar）

一个 macOS 原生本地应用：输入任务 → 拖到月历排期 → 拖拽调整时间跨度。

- 原生 SwiftUI，标准 macOS 窗口与控件
- **多主题系统**：内置 6 套高差异化主题（薄荷巧克力 / 柠檬汽水 / 巧克力可可 / 蜜桃气泡 / 海盐焦糖 / 抹茶拿铁），每套含**浅色 + 深色**两套完整语义色（品牌/背景/文字/边框/状态/优先级/标签/图表色板）；顶栏右侧画笔图标切换主题、月亮/太阳图标切换明暗，均自动记忆
- 月份视图：标题突出显示 **大号「M月」+ 上方小号「yyyy年」**
- 图标：黑底 + 白色**英文花体字** "Task / Calendar"（同字号上下排列），已出现在启动台（Launchpad）
- **纯本地运行**，无任何云存储 / 网络依赖
- 任务数据保存在：`~/Library/Application Support/DesktopTaskCalendar/tasks.json`

- 项目目录：`~/DoubaoWork/chats/2026-09-29/new-chat-2/TaskCalendar/`（源码与副本）

## 使用方式

1. 顶部输入任务名称，回车或点「添加」；右侧色点给任务选颜色（低饱和配色）。
2. 待排任务显示在胶囊条里，**按住拖到日历任意日期**即完成排期（默认占一天）。
3. 日历上的彩色任务条支持三种拖拽：
   - 拖任务条**中间**：整体平移任务
   - 拖任务条**右边缘**：延长/缩短结束日（拖出 10.1 → 10.7 这种跨度）
   - 拖任务条**左边缘**：调整开始日
   - 拖动按天吸附，跨周任务自动跨行显示
4. 右键任务条：「移除排期（回到待排列表）」或「删除任务」。
5. 左上角切换上/下月、「回到今天」；标题栏为标准红绿灯按钮，支持 Cmd+Q 退出。

## 数据与注意事项

- 所有数据只存在本机 `tasks.json`，删除该文件即清空数据。
- 窗口位置会被记住，重启后保留。

## 重新构建（可选）

需要 Xcode Command Line Tools（本机已具备）：

```bash
cd TaskCalendar
swift build -c release
cp .build/release/TaskCalendar ../TaskCalendar.app/Contents/MacOS/TaskCalendar
cp /tmp/AppIcon.icns ../TaskCalendar.app/Contents/Resources/AppIcon.icns  # 或用 make_icon.swift 重新生成
codesign --force --deep -s - ../TaskCalendar.app
```
