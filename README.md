# 桌面任务日历（Desktop Task Calendar）

一个 **macOS 原生本地任务管理应用**：输入任务 → 拖到月历排期 → 拖拽调整时间跨度，**纯本地运行，无任何云存储 / 网络依赖**。

![App 图标](icon.png)

## 特性

- **原生 SwiftUI**，标准 macOS 窗口与控件，适配系统观感
- **月历拖拽排期**：任务条支持三种拖拽
  - 拖**中间**：整体平移任务
  - 拖**右边缘**：延长/缩短结束日（例如拖出 10.1 → 10.7 的跨日跨度）
  - 拖**左边缘**：调整开始日
  - 按天吸附；跨周任务自动跨行显示
- **多主题系统**：内置 6 套高差异化主题 × 浅色/深色双模式，一键切换、自动记忆
- 月份标题突出显示：大号「M月」+ 上方小号「yyyy年」
- 图标为黑底白色**英文花体字** "Task / Calendar"，已注册到启动台（Launchpad）
- 数据只存本机：`~/Library/Application Support/DesktopTaskCalendar/tasks.json`

## 安装

**方式一：直接下载安装包**

从仓库下载 `桌面任务日历-v1.8.zip`，解压后把 `TaskCalendar.app` 拖入 `/Applications`（或双击运行）。

**方式二：从源码构建**

需要 macOS 13+ 与 Xcode Command Line Tools：

```bash
cd TaskCalendar
swift build -c release
# 应用包结构参考仓库根目录 TaskCalendar.app/
cp .build/release/TaskCalendar ../TaskCalendar.app/Contents/MacOS/TaskCalendar
codesign --force --deep -s - ../TaskCalendar.app
```

## 使用方式

1. 顶部输入任务名称，回车或点「添加」；右侧色点给任务选颜色（跟随当前主题的标签色板）。
2. 待排任务显示在胶囊条里，**按住拖到日历任意日期**即完成排期（默认占一天）。
3. 日历上的任务条支持三种拖拽（见上文特性）。
4. 右键任务条：「移除排期（回到待排列表）」或「删除任务」。
5. 左上角切换上/下月、「回到今天」；顶栏右侧画笔图标切换主题、月亮/太阳切换明暗；标题栏为标准红绿灯按钮，支持 Cmd+Q 退出。

## 数据与注意事项

- 所有数据只存在本机 `tasks.json`，删除该文件即清空数据（无云同步）。
- 窗口位置会被记住，重启后保留。
- 首次运行若提示"无法验证开发者"，请在「系统设置 → 隐私与安全性」中允许打开，或在终端执行：

```bash
xattr -dr com.apple.quarantine /Applications/桌面任务日历.app
```
